Notice you never compared Bo with Cy directly. If Bo is shorter than Ada and Ada is shorter than Cy, then Bo is shorter than Cy. That shortcut is called transitivity.

Go deeperthe rule, in symbols and code

For any heights a, b, c: if a < b and b < c, then a < c. Sorting algorithms lean on this to skip comparisons.

def shortest(hs):
    best = hs[0]
    for h in hs[1:]:   # one comparison per robot
        best = min(best, h)
    return best
