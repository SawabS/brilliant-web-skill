Design system · captured October 2026

A tutor's toolkit, in tokens

The Brilliant visual language: white canvas, black ink, a serif for big ideas, a friendly sans for everything else, buttons with a physical lip, and colour that always means something.

Colour ramps

Fourteen hue ramps, 50 → 950. Semantic roles (below) are what components use; reach for a ramp only for charts, illustrations and course colours.

Semantic roles

Every role has a light and a dark value. Toggle the theme (bottom right) to see them flip.

Type

Display styles are the serif (CoFo Robert → Besley, a Clarendon) at weight 500. Everything else is the sans (CoFo Brilliant → Inter). Interactive readouts use a semi-mono, code uses Source Code Pro, maths uses KaTeX.

Buttons

The 3D button is the product's signature: a face resting 4px above a solid lip. Press it and it sinks. Flat pills are for navigation and marketing.

# count the swaps bubble sort makes
def swaps(xs):
    n = 0
    for i in range(len(xs)):
        for j in range(len(xs) - i - 1):
            if xs[j] > xs[j + 1]:
                xs[j], xs[j + 1] = xs[j + 1], xs[j]
                n += 1
    return n  # "done"
